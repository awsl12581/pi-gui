# pi-gui 第一方扩展

> 最后修改时间：2026-10-18 20:45 CST
> 文档版本：v1
> 修改说明：明确维护中插件的归属、现有加载方式和未来内置计划。

本目录存放 pi-gui 持续维护的第一方插件，使用 Pi extension 与可选桌面视图实现。

| 插件                             | 功能                                                   |
| -------------------------------- | ------------------------------------------------------ |
| [GitHub](github/README.md)       | 浏览 PR/issue，提供模型读取工具。                      |
| [PR Review](pr-review/README.md) | 模型评审 PR、保存结构化问题、准备修复草稿。            |
| [Test Runs](test-runs/README.md) | 运行当前配置的演示测试套件，展示输出并支持取消和超时。 |
| [Usage](usage/README.md)         | 用量卡片、跨会话统计与上下文估算。                     |
| [Trace](trace/README.md)         | 模型和工具调用追踪及上下文详情。                       |

开发、构建、手动加载和本地分发见[第一方扩展指南](../docs/guides/first-party-extensions.md)。

当前仍由 Pi 配置显式加载，项目维护其类型、构建、测试和浏览器产物。打包内置是后续规划，尚未加入自动包含、注册或默认启用。业务仍归插件，通用宿主归 desktop，作者协议归 packages/extension-ui。
